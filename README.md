# 무한 크로스워드

아래로 끝없이 이어지는 한글 가로세로 낱말 퍼즐. 학습용 단어장을 골라서 푼다.

- **로봇 기초** — 협동로봇, 서보모터, 감속기, 티치펜던트, AGV, ROS …
- **로봇 심화** — 하모닉드라이브, 플렉스플라인, 서큘러스플라인, 나브테스코 …
- **시사 용어** — 비상계엄, 검찰개혁, 노란봉투법, 탄소중립 … (요즘 말이 앞자리)
- **어린이 어휘** — 해바라기, 미끄럼틀, 정월대보름, 우주비행사 …
- **동물 퀴즈** — 고슴도치, 딱따구리, 황제펭귄, 오리너구리 … (기초부터)

어린이 쪽은 둘로 갈라 두었다. 동물은 `동물 퀴즈` 로 독립했고, `어린이 어휘` 에는
자연·먹을거리·학교·놀이·명절만 남겼다. 두 단어장에 같은 말이 겹치지 않는다.

단어장은 이 다섯이다. 단어장을 고르면 바로 시작한다.

브라우저만 있으면 된다. 빌드도, 서버도, 외부 라이브러리도 없다.

**여는 곳**: <https://kimtaenim.github.io/crossword/>
(레포 Settings → Pages → Source: `Deploy from a branch` → Branch `main`, 폴더 `/ (root)`.
푸시할 때마다 Actions 탭에서 "pages build and deployment" 가 돌고 한 발쯤 뒤에 반영된다.)

단어장을 `fetch` 로 읽으므로 `index.html` 을 파일로 바로 열면(file://) 브라우저가 막는다.
로컬에서 볼 때는 `npx http-server .` 처럼 아무 서버나 띄우면 된다.
한 파일로 합쳐 어디든 붙여 넣고 싶으면 `node tools/bundle.mjs`.

## 노는 법

스크롤로 내려가며 푼다. 화면 안의 칸은 순서 없이 아무 때나 풀 수 있고,
**맨 위 한 밴드가 빈틈없이 다 풀리면 그 줄은 "지나온 줄"이 되어 위에 남는다.**
지워지지 않으므로 위로 올리면 언제든 다시 읽을 수 있다(복습). 대신 지나온
밴드일수록 코발트가 한 단계씩 옅어져, 처리한 데라는 것이 색으로 보인다.
아래는 계속 새로 생성되므로 끝이 없다.

- 칸을 누르면 선택, 같은 칸을 다시 누르면 가로↔세로 전환
- 글자는 **늘 쓰던 자판**으로 친다. 폰은 칸을 누르면 평소 한글 자판이 올라오고,
  PC는 한/영이 한글이든 영문이든 두벌식대로 치면 된다.
- 스페이스 = 방향 전환, Tab = 다음 단어
- 💡 = 한 칸 열기, 🔓 = 그 단어 통째로 열기 (둘 다 점수가 깎인다)
- 다 채웠는데 틀린 단어는 **칸이 레몬색**이 된다. 밴드가 안 걷히면 노란 데를 보면 된다.
  어느 칸이 틀렸는지까지는 알려 주지 않는다 — 그건 답을 알려 주는 것이나 같다.
- 기기 자판이 말을 안 들으면 ⌨ 로 **내장 자판**(두벌식)을 꺼내 쓸 수 있다.
  ⇧ 는 한 글자짜리다 — 다음 자음 하나에만 걸리고, 지우거나 다른 칸으로 옮기면 곧 풀린다
- AGV·SLAM 같은 **알파벳 약어 칸을 고르면 영문 자판이 저절로 올라온다**.
  한글 자판을 켜 둔 폰에서 로마자를 치기가 번거로워서, 이때만은 내장 자판을 쓴다.
  PC 는 그냥 알파벳을 치면 되고, 소문자로 쳐도 대문자로 들어간다.
- 지나온 줄의 칸을 눌러도 그 단어의 힌트를 다시 읽을 수 있다. 답을 이미 아는 채로
  힌트를 다시 보는 것이라, 외우려고 푸는 판에서는 이게 오히려 본론이다.
- 왼쪽 위 단어장 이름을 누르면 단어장을 바꿀 수 있다. 진행 상황은 단어장마다 따로 저장된다.
- **나갔다 들어와도 그대로 이어진다.** 판과 채워 둔 글자, 점수, 고르고 있던 칸,
  보던 자리까지 `localStorage` 에 남는다. 저장된 자리가 아직 안 만들어진 줄이면
  거기까지 먼저 깔고 옮긴다. 폰은 앱을 내리는 순간 프로세스가 죽을 수
  있어서, 미뤄 둔 저장을 `visibilitychange`·`pagehide` 에서 그 자리에서 마친다.

## 지나온 줄을 남긴다

처음에는 다 푼 줄을 지우고 남은 판을 위로 끌어올렸다. 화면은 깔끔했지만
방금 외운 단어를 다시 볼 방법이 없었다. 지금은 **지우지 않고 남긴다.**

  · 다 푼 줄은 `past` 로 표시만 바뀌고 자리에 그대로 있다
  · 좌표가 밀리지 않으므로 홀짝도 밴드 경계도 번호도 흔들리지 않는다
    (걷어내던 시절에는 이것들을 매번 다시 맞춰야 했다)
  · **단계는 둘뿐이다.** 방금 넘긴 밴드는 다 맞힌 칸과 거의 같은 진하기로 남고,
    그 위는 한꺼번에 뚝 떨어져 옅은 바탕이 된다 (밝기로 재면 122 → 236)
  · 처음에는 다섯 단계로 슬금슬금 옅어지게 했는데, 그러면 방금 해낸 줄이
    묻혀 «여기까지 왔다» 가 안 보인다. 확 갈리는 편이 낫다
  · 방금 넘긴 줄은 흰 글자, 그 위는 옅은 바탕이라 흰 글자로는 안 읽히므로
    글자를 짙게 둔다. 복습하려고 남기는 것이니 읽히는 쪽이 먼저다
  · 0.55초에 걸쳐 옅어진다 — 넘어가는 순간이 눈에 보이게
  · 경계에는 "여기부터 푸는 중" 이라는 점선을 둔다
  · 넘어간 뒤에는 시선만 아래로 따라 내려간다 (판은 가만히 있는다)

대신 판이 끝없이 길어지므로 두 가지를 둔다. **화면 언저리 열네 줄만 DOM 에
두고**(그 밖은 지웠다가 다시 올라오면 다시 그린다), **240줄이 넘게 지나온 것은
버린다**(`KEEP`). 버릴 때는 세로 단어가 걸치지 않은 줄까지 물러나 자른다 —
아무 데서나 자르면 반쪽짜리 단어가 남는다.

## 시사 용어는 «요즘 말» 이 앞에 온다

시사 단어장은 두 갈래다 — **요즘 말 75개**와 **시사 용어 183개**.
요즘 말은 지어낸 것이 아니라, 시사IN 챗봇 프로젝트의 기사 뭉치
(2025-10 ~ 2026-09, 1100건)를 훑어 **실제로 최근에 자주 다뤄진 말**만 골랐다.
지방선거, 비상계엄, 검찰개혁, 공소청, 내란우두머리, 노란봉투법, 데이터센터,
이주노동자, 중대재해, 전기요금, 가자지구 …

앞에 온다는 건 순서만이 아니다. 요즘 말에는 배치 가산점(`NEW`)을 준다.
단어장에서 차지하는 비중은 32% 인데 **판에 나오는 낱말의 54%** 가 요즘 말이 된다.
그러고도 채움 0.40 / 겹침 1.53 으로 판은 촘촘하다.

새 기사가 쌓이면 다시 훑으면 된다.

```
node tools/sisain-scan.mjs ../sisain-chatbot
```

  · 단어장에 있는데 요즘 기사에 한 번도 안 나온 말 (묵었는지 볼 것)
    — 찾을 때 띄어쓰기를 지우고 맞춘다. 안 그러면 "표현의 자유" 로 스물한 번
      나온 말이 «표현의자유» 로는 한 번도 안 나온 것이 되어 애먼 말이 묵은 말이 된다
  · 단어장에 있고 요즘도 자주 나오는 말 (잘 고른 말)
  · 단어장에 없는데 요즘 자주 나오는 말 (넣을 만한 말)

### 빈도만 세면 «어떻게» 가 일 등을 한다

처음 만든 판은 «아니라», «어떻게», «때문에» 를 맨 위에 올려놓고 사람더러 고르라고
했다. 그건 도구가 할 일을 미룬 것이다. 지금은 네 가지로 거른다.

**① 조사가 붙는가.** 한국어 명사는 뒤에 은·는·이·가·을·를·의·에 가 붙고
부사와 어미는 안 붙는다. 코퍼스에서 바로 잴 수 있다.

```
어떻게 0.00   아니라 0.05   그러나 0.00   있다는 0.00
지방선거 0.43  검찰개혁 0.40  데이터센터 0.44  헌법재판소 0.67
```

**② 조사가 여러 가지 붙는가.** ①만으로는 «그럼에도» 의 잘린 토막 «그럼에» 가
비율 1.00 으로 올라온다 — 뒤에 «도» 만 붙기 때문이다. «대상으» 는 «로» 만 붙는다.
진짜 명사는 이/가/를/의/에서… 서너 가지가 두루 붙으므로 종류 수도 함께 센다.

**③ 조사를 겹쳐 뗀다.** «앞으로는» 은 «는» 만 떼면 «앞으로» 가 남아 명사처럼
보인다. 더 뗄 것이 없을 때까지 되풀이해서 떼고, 그러고도 세 글자가 넘어야 후보다
(«한국에서» → «한국» 두 글자 → 버린다).

**④ 사람·매체 이름과 너무 흔한 말을 뺀다.** 온톨로지의 인물·매체 엔티티(이재명,
연합뉴스)를 빼고, 최근 기사 열 건에 한 건 넘게 나오면 일반 명사로 보아 버린다.
그래도 남는 «이미지», «분위기» 같은 말은 손으로 적은 목록에서 걸러 낸다.

이렇게 거르면 «보완수사권», «형사소송법», «전당대회», «최고위원», «재판부» 처럼
넣을 만한 말만 남는다. 실제로 이 목록에서 스물다섯 개를 골라 넣었다.
고르고 힌트를 쓰는 것은 여전히 사람 몫이지만, 사람이 볼 것은 이제 쓸모 있는 목록이다.

반대쪽도 사람이 판단한다. 이 뭉치에 한 번도 안 나온 말이 스무 개 남아 있지만
그렇다고 다 묵은 것은 아니다 — 부가가치세·상속세·독점규제·낙수효과는 뉴스에
매일 안 나와도 시사 어휘의 기본이다. 한 시절의 구호였다가 지나간 일곱 개만 뺐다:
집단면역, 물류대란, 항만적체, 유니콘기업, 망중립성, 수소경제, 반도체패권.

## 어려우면 «쉽게»

로봇 용어는 처음 보는 사람에게 너무 가팔랐다. 단어장 고르는 화면의 **쉽게**
스위치를 켜면 둘이 달라진다.

  · **아무 데도 안 걸린 낱말만 첫 글자를 연다.** 처음에는 낱말마다 열어 봤는데
    그러면 떠올릴 일이 없어져 외우려고 푸는 판에서 남는 게 없었다. 다른 낱말과
    한 칸도 겹치지 않는 낱말은 힌트 말고 실마리가 아예 없으니 거기만 준다 —
    한 화면에 마흔 남짓 중 두어 개다(보스턴다이내믹스, 웨이브제너레이터처럼
    길고 안 물리는 말들이 딱 그렇다).
  · **기초 낱말을 먼저 깐다.** 하드 필터가 아니라 벌점(`HARD`)이라 판은 그대로
    촘촘하다 — 200줄 기준 기초 비율이 47% 에서 76% 로 오르고, 채움 0.40 / 겹침 1.48.
  · 💡 값도 8점에서 4점으로 덜 깎는다.

단어장에 `기초` 를 달려면 갈래 이름을 `기초` 로 두거나, 낱말의 네 번째 칸에 적으면 된다.

```json
["서보모터", "시킨 각도까지 돌고는, 손으로 밀어도 그 자리를 버티고 서 있는 부품", "구동계", "기초"]
```

## 기초부터 — 갈래로도, 단어장으로도

**로봇은 단어장을 아예 둘로 갈랐다.** `로봇 기초` 132개와 `로봇 심화` 70개다.
진행과 점수가 따로 남으므로 기초를 뗀 다음 심화로 넘어가는 흐름이 그대로 보인다.
기초만 떼어 놓으니 88개로는 판이 성겨서(겹침 1.11) 입문 용어 44개를 더 채웠다 —
이족보행, 컨베이어, 비상정지, 서빙로봇, 원점복귀, 유지보수, 근접센서처럼
현장에서 제일 먼저 만나는 말들이다.

**동물 퀴즈는 한 단어장 안에서 갈래로 나눴다.** 기초 116개(고슴도치, 딱따구리,
돌고래, 무당벌레, 강아지 …)와 심화 85개(스라소니, 향유고래, 대왕조개, 변온동물 …).
동물만 담지는 않았다 — 사육사, 동물병원, 산책줄, 배변봉투처럼 동물과 사는 데
따라오는 말도 함께 둔다. 어린이가 동물을 배우면서 같이 만나는 말들이다.
단어장 파일에 이렇게 적어 두면 처음 고를 때 그 갈래만 켜진 채로 시작한다.

```json
"default": ["기초"]
```

고른 갈래는 하드 필터가 아니라 우선순위다. 기초만 켜도 판에 나오는 낱말의 89% 가
기초이고, 남는 자리는 심화가 메워 채움 0.35 / 겹침 1.42 로 촘촘하다.
심화도 함께 보고 싶으면 단어장 이름을 눌러 갈래 화면에서 켜면 된다.

둘 중 어느 쪽으로 나눌지는 단어 수가 정한다. 갈래로 나누면 남는 자리를 서로
메워 주어 판이 안 성기고, 단어장으로 가르면 진행이 따로 남는 대신 각각
백 개는 넘어야 판이 버틴다.

## 힌트가 본문이다

푸는 사람이 실제로 읽는 것은 격자가 아니라 힌트다. 그래서 힌트를 한 줄에 욱여넣고
말줄임표로 자르던 것을 걷어내고, 화면 아래를 힌트 칸으로 통째로 내주었다.
17px, 두 줄까지 그대로 보인다(가장 긴 힌트가 46자라 두 줄에 들어간다).
번호·방향·갈래·글자 수는 그 위에 작게 얹고, 버튼은 아래 한 줄로 내려 이름을 붙였다.

## 보이는 것

델프트 도자기다 — 흰 유약을 두껍게 입힌 살결에 코발트 하나로만 그린다.
빈 칸은 흰 타일, 다 맞힌 칸은 코발트로 그리고 유약을 덮어 구워 낸 타일이 된다.

유약은 두 가지로 흉내 낸다. **위에서 아래로 옅어지는 결**(`--glaze`)과
**가장자리 안쪽에 한 줄 도는 흰 빛**(`--sheen`, `inset` 그림자). 파란 타일은
같은 걸 뒤집어 쓴다 — 위쪽에 흰 빛 한 줄, 아래쪽에 짙은 그늘(`--sheen-blue`).
글자에도 옅은 그림자를 얹어 유약 아래 가라앉은 것처럼 보이게 했다.
바탕은 위쪽에서 빛이 도는 아주 옅은 방사형 얼룩 둘로 살결을 냈다.

다 채웠는데 틀린 단어는 붉은색 대신 **레몬색**으로 물든다. 붉은색은 "고장"으로
읽히지만 여기서 틀림은 아직 손볼 수 있는 상태여서, 눈에는 띄되 겁주지 않는 쪽을 골랐다.
색과 유약은 `index.html` 맨 위 `:root` 의 토큰 열몇 개가 전부다.

## 어린이 단어장은 민트에 스티커

어른 단어장은 흰 타일과 코발트만으로 충분한데, 어린이 쪽은 그러면 휑하고 딱딱하다.
`어린이 어휘` 와 `동물 퀴즈` 는 **배색과 스티커**를 따로 쓴다.

```json
"theme": "mint",
"deco": ["🐶","🐱","🐰","🐻","🐼","🦊","🐯","🐸","🐥","🦋","🐝","🐢","🦔","🐙","🐳","🦄",
         "🌈","❤️","🎈","👽","✨","💖","🌟","🎀","🍀","🫧","🛸","🌼","🍄","🎵","💫","🧡"]
```

**민트.** 델프트가 코발트라면 이쪽은 밝은 파스텔 민트다. 갈아 끼우는 것은 `:root` 토큰
열몇 개뿐이라 유약도 그늘도 지나온 줄의 다섯 단계도 그대로 따라온다.
`body[data-theme="mint"]` 한 겹으로 덮으므로, 다른 배색을 더 넣고 싶으면
토큰 블록 하나만 더 쓰면 된다. `theme` 이 없는 단어장은 그대로 델프트 블루다.

**스티커.**

  · 자리도 그림도 크기도 기울기도 **좌표만으로** 정한다. 그래서 스크롤해서
    다시 와도 그 자리에 그대로 있다 (어림수를 쓰면 볼 때마다 춤을 춘다)
  · 여섯 자리에 하나꼴로 팍팍 붙는다. 칸이 있는 자리에는 절대 안 붙고,
    나중에 그 자리에 칸이 생기면 저절로 비켜난다
  · 그림은 동물만이 아니다 — 무지개, 하트, 풍선, 외계인, 비눗방울까지 섞는다.
    낱말은 동물만 남겼지만 스티커까지 그럴 이유는 없다
  · 누를 수 없다 (`pointer-events: none`) — 푸는 데 걸리적거리지 않는다
  · 지나온 줄 위에서는 함께 흐려진다

단어장에 `deco` 가 없으면 아무것도 안 붙는다. 로봇과 시사는 그대로 담백하다.

한 가지 걸렸던 것: 자리를 고른 해시로 그림까지 고르면 안 된다. 아홉 자리에
하나씩 놓느라 `h % 9 === 0` 인 것만 남겨 놓고 같은 `h` 로 `h % 18` 을 하면
값이 둘뿐이라(9와 18은 약수 관계) 판에 강아지와 개구리만 깔렸다. 그림은
좌표를 뒤집어 넣은 **다른 해시**로 고른다.

## 격자를 어떻게 짜는가

크로스워드는 단어가 짧으면 볼 게 없다. 그래서 단어장은 4~5음절 위주로 모았고,
격자도 겹침이 많이 나오도록 규칙을 박아 두었다.

```
가로 단어 → 한 줄 걸러 한 줄("가로줄")에만
세로 단어 → 짝수 칸에만, 가로줄에서 시작, 홀수 글자, 한 밴드 안에서 끝
```

칸은 한글 음절과 알파벳 대문자를 둘 다 받는다. 겹침은 글자가 같아야 생기므로
약어는 약어끼리만 물린다(AMR 과 AGV 가 A 에서 만나는 식). 덕분에 한 칸이
한글 단어와 영문 단어에 동시에 속하는 일은 없고, 고른 단어만 보면 어느 자판을
올려야 할지가 정해진다.

이러면 새로 놓는 칸이 직각 방향 이웃과 맞닿는 일이 아예 없다. 뜻 없는 두 글자
덩어리가 생길 걱정 없이 촘촘하게 짤 수 있다는 뜻이다. 대신 **겹침은 한 칸 걸러
한 칸에서만 생긴다** — 네 글자 단어는 최대 두 번, 다섯 글자는 세 번, 일곱 글자는
네 번까지 겹칠 수 있다. 긴 단어를 모은 이유가 이것이다.

밴드(6줄)는 세로 단어가 절대 넘지 않는 경계다. 덕분에 밴드 경계는 언제나
"걷어낼 수 있는 줄"이 되어, 촘촘한 격자와 걷어내기 규칙이 부딪히지 않는다.

한 밴드를 짤 때는 이미 놓인 단어에 **한 글자만** 걸치는 자리를 번갈아 늘려 간다.
가로줄을 먼저 다 채워 놓고 세로를 끼우려 하면 세로 단어가 서너 글자를 한꺼번에
맞춰야 해서 거의 안 들어간다. 같은 밴드를 열두 번 짜 보고 제일 촘촘한 것을 남긴다.

### 더 잘게 나누고 싶어지면

단어마다 소분류를 붙여 두었다. 세 번째 칸이 그것으로, 지금은 힌트 줄에
같이 보여 주기만 하고 고르는 데는 쓰지 않는다.

```js
["액추에이터", "생각만 하던 걸 드디어 몸으로 옮겨 주는 부품", "로봇 만들기"],
```

`packs/*.json` 의 `groups` 를 소분류대로 쪼개면 갈래 고르는 화면이 저절로 살아난다
(갈래가 둘 이상이면 뜨고, 하나면 건너뛴다). 다만 잘게 쪼갠 갈래 하나만 켜면
판이 상한다. 한 갈래가 서른몇 개뿐이라 서로 물릴 음절이 모자라서, 하드 필터로
해 보면 채움이 0.19 까지 떨어지고 겹치는 데가 없는 단어가 절반 가까이 나온다.
그래서 고른 갈래에 가산점만 주고 남는 자리는 같은 단어장에서 채우게 해 두었다
(`OFFPICK`). 벌점을 겹침 하나 값(100) 위로 올리면 하드 필터가 되고, 그때
고른 갈래 비율은 100% 가 되지만 채움 0.30 / 겹침 0.78 로 무너진다.

### 지금 나오는 수치

단어장마다 200줄을 생성해서 잰 값이다.

| 단어장 | 단어 수 | 4글자 이상 | 채움 비율 | 단어당 평균 겹침 | 200줄에 나온 단어 |
|---|---|---|---|---|---|
| 로봇 기초 | 132 (약어 16) | 72% | 36% | 1.2 | 93개 |
| 로봇 심화 | 70 (약어 19) | 80% | 39% | 1.2 | 63개 |
| 시사 용어 | 251 (요즘 말 75) | 82% | 40% | 1.5 | 102개 |
| 어린이 어휘 | 163 | 50% | 34% | 1.3 | 111개 |
| 동물 퀴즈 | 201 (기초 116) | 40% | 38% | 1.5 | 129개 |

`로봇 스터디` 는 「로봇 스터디 마스터 문서」의 용어 지도·용어 해부·부수 용어 사전에서
뽑았고, 거기에 ROS·TCP·PID·HMI 처럼 현장에서 그 이름으로만 부르는 약어를 더해
35개가 됐다. 반대로 **현장에서 약어로 부르는 말은 한글 이름을 뺐다** — 아무도
"자율이동로봇"이라 하지 않고 AMR 이라 하며, 무인운반차·동시위치추정·관성측정장치도
마찬가지다. 한 뜻에 두 이름을 두면 힌트도 둘로 갈라진다.

알파벳은 오히려 한글보다 잘 물린다. 같은 판에서 재 보면 약어 1.6, 한글 1.31 —
세 글자에 A·S·R 처럼 흔한 글자 가 몰려 있어서다. 판에 나오는 단어의 28% 가
약어가 되는데(단어장 비중은 22%), 그만큼 한글 쪽 겹침을 조금 내주고 있다.

같은 단어를 여러 번 쓴 것에는 벌점을 매긴다. 안 그러면 음절이 잘 물리는
서른몇 개만 계속 돌려 쓰는데(200줄에 35개), 외우려고 푸는 판에서는 그게 더 나쁘다.
겹침을 1.7에서 1.5로 조금 내주고 나오는 단어를 두 배로 늘렸다.

단어당 겹침을 3~4회로 올리려면 격자가 아니라 **단어 수**를 늘려야 한다.
지금은 단어장 하나가 200개 남짓이라, 세 번째 단어를 끼울 때 이미 놓인 단어
서넛의 글자를 동시에 맞춰야 하는 자리에서 거의 실패한다. 실제로 이 단어장들에는
서로 완전히 맞물리는 3×3 / 4×4 단어 사각형이 하나도 없다. 단어를 몇 배로 늘리면
같은 격자 규칙 그대로 겹침이 올라간다.

`동물 퀴즈` 는 세 글자짜리 이름이 많아 4글자 이상이 44% 뿐인데도 겹침이 1.5 나온다.
동물 이름은 `-이`, `-리`, `-새`, `물-` 처럼 같은 음절을 나눠 갖는 말이 유난히 많아서다.

두 글자 이름(하마, 기린, 홍학)은 격자에 못 쓴다. 처음에는 하마입·기린목·홍학떼처럼
뒤에 한 글자를 붙여 늘렸는데, 억지로 만든 말이라 문제로 나오면 맥이 빠진다.
**진짜로 쓰는 세 글자 이상 이름으로 갈아 끼웠다** — 서른한 개다.

```
고슴도치굴 → 개미핥기   뱀허물 → 능구렁이   개미집 → 하늘다람쥐  하마입 → 하이에나
기린목 → 카피바라       자라목 → 왜가리     치타달리기 → 청둥오리 홍학떼 → 가마우지
참새떼 → 오목눈이       깃털옷 → 곤줄박이   문어다리 → 갑오징어   타조알 → 방아깨비
꿀벌집 → 딱정벌레       말벌집 → 하늘소     낙타혹 → 단봉낙타     악어이빨 → 바다악어
```

까치집, 제비집, 거미줄, 사슴뿔, 알껍데기, 짝짓기는 남겼다 — 사전에 있는 말이고
아이가 배울 값도 있다. 억지로 지어낸 것과 실제로 쓰는 말의 차이다.

## 힌트는 사전이 아니다

정의를 그대로 옮겨 적으면 읽다가 잠이 온다. 그렇다고 농담만 얹으면 못 맞힌다.
그래서 규칙을 하나 세웠다 — **장면이 곧 정의여야 한다.** 뜻과 상관없는 곁가지를
뒤에 붙이지 않고, 그 말이 하는 일을 눈에 보이게 쓴다.

> **라벨링** — 고양이 사진 만 장에 '고양이'라고 일일이 적어 넣는 일
> **환각현상** — 없는 논문을 저자와 연도까지 붙여 당당하게 알려 주는 것
> **과적합** — 작년 기출은 다 맞히는데 올해 문제는 하나도 못 맞히는 상태
> **역기구학** — 손끝을 저 컵에 두려면 관절을 몇 도씩 꺾어야 하는지 푸는 일
> **감속기** — 모터는 빨리 도는데 팔은 느리고 힘 있게 움직이게 만드는 부품
> **실질임금** — 월급은 3% 올랐는데 물가가 4% 오르면 깎인 셈이 되는 그것
> **부동산시장** — 옆 동이 얼마에 팔렸는지로 내 집값이 정해지는 판
> **디지털격차** — 키오스크 앞에서 누구는 삼 초, 누구는 삼 분 걸리는 차이
> **올챙이** — 꼬리로 헤엄치다가 다리가 나고 꼬리가 없어지는 것
> **오리너구리** — 알을 낳는데 젖을 먹이고 부리까지 달린 이상한 짐승
> **뻐꾸기** — 남의 둥지에 알을 몰래 낳아 놓고 가 버리는 새
> **낙타혹** — 물이 아니라 지방을 채워 두고 오래 버티게 해 주는 것
> **방학숙제** — 한 달 내내 미루다 개학 전날 밤에 몰아 하는 것

이렇게 쓰기 전에 두 번 헛돌았다. 처음엔 사전 문장이라 지루했고, 다음엔 농담을
넣느라 정작 뜻을 빼먹어 못 맞히는 힌트가 됐다. 세 번째에 겨우 규칙을 찾았다.

다치는 사람이 있는 주제(산업재해, 난민문제, 인권침해 같은)는 농담을 얹지 않고
담백하게 뒀다. 어린이 어휘는 빈정대지 않고 장난스러운 쪽으로 썼다.

`node tools/check-clues.mjs` 로 힌트를 점검할 수 있다. 정답이 그대로 들어갔는지,
정답의 두 음절이 붙어서 새는지(`서보모터` 힌트에 "모터"), 두 줄을 넘길 만큼 긴지,
다른 힌트와 똑같은지를 잡아낸다. 다시 쓸 때마다 서너 건씩 걸렸다.

## 단어장 추가하기

단어장은 `packs/` 아래 JSON 파일 하나씩이다. 파일을 만들고 `packs/index.json` 에
이름만 더하면 끝. 코드는 손댈 데가 없다.

```json
{
  "id": "law",
  "name": "법률 용어",
  "emoji": "⚖️",
  "desc": "계약서 아래쪽 작은 글씨에 숨어 있는 말들",
  "groups": [
    {
      "name": "법률 용어",
      "words": [
        ["손해배상", "남에게 끼친 손실을 물어 주는 일", "계약과 책임"]
      ]
    }
  ]
}
```

한 줄이 단어 하나다 — `[단어, 힌트, 소분류]`. 소분류는 힌트 줄에 같이 보여 주기만
하고 고르는 데는 쓰지 않는다(→ 아래 "더 잘게 나누고 싶어지면").

4~5음절이 가장 잘 물린다. 힌트에 정답 음절을 넣지 말 것.
쓰고 나서 `node tools/check-clues.mjs` 를 꼭 돌릴 것.

## 구조

```
index.html            화면과 스타일
game.js               한글 조합기 · 격자 생성 · 입력 · 저장
packs/index.json      읽어 올 단어장 파일 목록
packs/*.json          단어장 (["단어","힌트","소분류"] 목록)
tools/check-clues.mjs 힌트 점검 (정답 노출·길이·중복)
tools/bundle.mjs      한 파일짜리 배포본 만들기
```

`game.js` 는 의존성이 없다.

한글 입력은 두 갈래다. 기본은 **기기 자판** — 보이지 않는 입력칸에 포커스를 주면
폰은 쓰던 자판(두벌식이든 천지인이든)이 올라오고, 브라우저가 만들어 준 조합 결과를
칸에 그대로 비춘다. 조합 중에는 줄을 걷어내지 않는다. 칸이 사라지면 비출 자리가
어긋나므로, 걷어내기는 조합이 끝나는 순간으로 미룬다. 조합 이벤트를 아예 안 보내고
완성된 음절만 밀어 넣는 자판(일부 천지인·음성 입력)에서도 같은 경로로 동작한다.

다른 갈래는 **두벌식 조합기**를 직접 돌리는 쪽이다. PC에서 한/영을 영문에 둔 채
치는 경우와 내장 자판이 여기로 온다 — 겹모음, 겹받침, 받침이 다음 글자 초성으로
넘어가는 경우(각+ㅏ → 가+가)까지 처리한다.

`?debug` 를 붙여 열면 콘솔에서 `__cw` 로 내부 상태를 볼 수 있다.
